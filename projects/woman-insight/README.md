# 👩 Woman Insight – Online Educational Platform
*(July 2021 – April 2023)*

**Project Overview:**
Woman Insight is an online educational platform dedicated to personal development, offering courses in spirituality, goals, business, family, hobbies, relationships, and health.

**Live Website:** [https://womaninsight.com/ru/courses/](https://womaninsight.com/ru/courses/)

- **Diverse Course Offerings** – Wide range of topics for personal development
- **Concise Lessons** – Each lesson up to 15 minutes for busy schedules
- **Personalized Learning Paths** – Tailored educational experiences

**Technologies Used:**
- Node.js
- Docker
- PostgreSQL
